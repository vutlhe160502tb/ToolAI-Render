# Landing (Next.js)

Landing page độc lập nằm trong folder `landing/` (không ảnh hưởng `frontend/` hiện có).

## Chạy local

```bash
npm install
npm --workspace landing run dev
```

Mặc định chạy tại `http://localhost:3000`.

## Build/Start

```bash
npm --workspace landing run build
npm --workspace landing run start
```
